# Support

Thank you for using PuppyClicker for Minecraft. You do not need to understand
Java, mod loaders, or the PuppyClicker API to ask for help.

## Choose the right place

| What you need | Where to go |
| --- | --- |
| Something in the mod is not working | Use the [bug report form](https://github.com/eimi-codes/puppyclicker-mc/issues/new?template=bug_report.yml) |
| Help installing or configuring the mod | Use the [help request form](https://github.com/eimi-codes/puppyclicker-mc/issues/new?template=help_request.yml) |
| An idea for the mod | Use the [feature request form](https://github.com/eimi-codes/puppyclicker-mc/issues/new?template=feature_request.yml) |
| A possible security problem | Follow the private instructions in [SECURITY.md](SECURITY.md) |
| A Code of Conduct concern | Email [minecraftclicker@eim.ie](mailto:minecraftclicker@eim.ie) |
| A PuppyClicker account or service problem unrelated to the mod | Visit [PuppyClicker](https://puppyclicker.app/) |

## Before opening an issue

Please check the following if you can:

- The JAR filename contains your exact loader and Minecraft version.
- Your loader, its API (for Fabric), and Java match the table in the
  [README requirements](README.md#requirements).
- The same PuppyClicker mod version is installed on the client and server.
- The API key begins with `pak_` and validates in
  **Mods → PuppyClicker for Minecraft → Config**.
- The problem has not already been reported in
  [open issues](https://github.com/eimi-codes/puppyclicker-mc/issues).

It is okay if you cannot find all these details. The help form will guide you
through the useful parts.

## Safe information to share

Useful information includes:

- What you were trying to do.
- What happened instead.
- The exact message shown above the hotbar or on the configuration screen.
- Minecraft, loader, Java, mod, launcher, and operating-system versions.
- Steps that make the problem happen again.
- Screenshots that do not contain credentials or private information.
- A log reviewed for secrets before upload.

## Never share these publicly

- A PuppyClicker API key, including any complete value beginning with `pak_`.
- A Minecraft access token or launcher credential.
- The contents of `config/puppyclicker-client.toml` or
  `config/puppyclicker-client.json`.
- Private information belonging to you or another person.

If a credential is exposed, remove it from the public post and replace or
revoke it through the relevant service immediately. Editing a post does not
guarantee that the original value was not retained elsewhere.

## Private contact

For project matters that should not be discussed in a public GitHub issue,
email [minecraftclicker@eim.ie](mailto:minecraftclicker@eim.ie). Security
reports should follow [SECURITY.md](SECURITY.md) so they contain the information
needed for a safe investigation.

This is a volunteer-maintained project. Reports will be reviewed when possible,
but response times cannot be guaranteed.
